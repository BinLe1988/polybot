## Filter definitions

### trend3 (close-to-close monotonic)
Relative to current 5m window start `ws`, take Binance BTCUSDT 5m closes for bar opens
`[ws-1200, ws-900, ws-600, ws-300]` (4 closes → **3** steps).
- Continuous **up**: each step `close[i] >= close[i-1]`
- Continuous **down**: each step `close[i] <= close[i-1]`
- Flat / mixed → no trend (block)
- Gate: Up-chase only if up; Down-chase only if down

### sr1000 (true vs false break)
Round levels every **$1000**. Probe last 4 completed 5m bars.
- Relevant level: Up → nearby resistance; Down → nearby support (within ±$150 of probe range)
- Pierce ≥ $20 beyond level
- **FALSE**: pierce then reclaim (close back through level) within 2 bars → **SKIP**
- **TRUE**: close beyond + hold (≥1 bar) with no later reclaim → allow
- **none** (not near / inconclusive) → allow (only block clear false breaks)

### Base R1/R2
Unchanged: R1 buy≥0.65 rem∈(120,240]; R2 buy≥0.80 rem>60; exit@0.99 or settle; $5; one side/window.
